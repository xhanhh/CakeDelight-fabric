# 蛋糕乐事 CakeDelight
一个农夫乐事（Farmer's Delight）附属，为MC添加了传送蛋糕、蛋糕有关模组与农夫乐事的联动和各种有趣的食物~

This mod adds cakes for teleportation between various dimensions(v3.1.0+), and adds the linkage between other cake-related mods and Farmer's Delight, as well as a small portion of food.
